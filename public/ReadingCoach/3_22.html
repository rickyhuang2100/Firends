工程師做什麼？

你喜歡弄清楚事物是怎麼運作的嗎？你對解決問題感到興奮嗎？如果是，你可能可以考慮成為一名工程師。

工程師努力尋找問題的解決方案。他們也設計幫助人們的新產品。

有些工程師致力於讓汽車更安全。有些工程師弄清楚如何建造堅固的橋樑。有些工程師開發新藥物或找到更好的方法保持食物新鮮和安全。

工程師首先識別要解決的問題或要設計的新產品。他們尋找修復問題或製造產品的方法。他們查看不同的想法並選擇最好的一個。

通常，工程師製作模型並測試它。他們尋找改進他們所做作品的方法。

Sandra Cruz-Pol 是一位工程師。她還在大學教工程學生。Sandra 設計的產品可以讓人們知道暴風雨和洪水何時到來。她說找到改善人們生活的方法感覺很好。

✏️ 文法重點解析

1. "If so, you might..."

如果是這樣，你可能...：

If so, you might think about becoming an engineer.
2. "work to + V"

努力去做...：

Engineers work to find solutions to problems.
3. "It feels good to + V"

做...感覺很好：

It feels good to find ways to improve people's lives.

💬 重要句型分析

句型 1: If so, + S + might + V
If so, you might think about becoming an engineer.
→ 如果是這樣，你可能會...
句型 2: work to + V
Engineers work to find solutions to problems.
→ 努力去做...
句型 3: It feels good to + V
It feels good to find ways to improve people's lives.
→ 做...感覺很好
句型 4: figure out how to + V
Engineers figure out how to build strong bridges.
→ 弄清楚如何做...
💡 實用表達
  • "find solutions to" → 找到...的解決方案
  • "think about + V-ing" → 考慮做...
  • "look for ways to" → 尋找方法來...
