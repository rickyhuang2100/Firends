🌏 中文翻譯

俳句

走到外面。你看到了什麼？許多詩人寫關於他們在大自然中看到的事物。很久以前，一些日本詩人觀察大自然，然後寫下短詩。這些短詩被稱為俳句。

一首俳句有三行。通常第一行有五個音節。第二行有七個音節，第三行有五個。俳句用很少的詞表達很多。上面的圖片是一首日文俳句。以下是它的翻譯：

今夜海浪洶湧
延伸到佐渡島上方
靜默的星雲

這首俳句是由一位非常著名的日本俳句詩人寫的。他的名字叫松尾芭蕉。他生活在17世紀。自17世紀以來，俳句一直是日本最受歡迎的詩歌形式。

今天，世界各地的人都寫俳句。甚至還有俳句比賽。人們寫什麼？現在，俳句可以是關於任何事的，但大自然仍然是一個熱門的主題。

人們寫俳句
表達他們所見的一切
少少的話語訴說很多

✏️ 文法重點解析

1. "These...are called..." 這些...被稱為

用被動語態來介紹專有名詞：

These short poems are called haiku.
→ 這些短詩被稱為俳句。
2. "Since + 時間, S + has/have been" 自從...以來

現在完成式表示從過去持續到現在：

Since the 17th century, haiku has been the most popular kind of poetry.
→ 自17世紀以來，俳句一直是最受歡迎的詩歌形式。
3. "continues to be" 繼續是

表示持續不變的狀態：

Nature continues to be a popular topic.
→ 大自然仍然是一個熱門的主題。

💬 重要句型分析

句型 1: S + expresses a lot by + V-ing
A haiku expresses a lot by using few words.
→ 用很少的詞表達很多
句型 2: Since + 時間, S + has been
Since the 17th century, haiku has been the most popular...
→ 自從...以來一直是
句型 3: These days, S + can be about...
These days, haiku can be about anything.
→ 如今，...可以關於任何事
💡 俳句小知識
  • 俳句格式：5-7-5 音節
  • 傳統主題：自然
  • 最著名的俳句詩人：松尾芭蕉（Matsuo Basho）
  • 現代俳句可以關於任何主題

🎯 閱讀理解技巧

文章結構：定義→歷史→現代

定義：俳句是日本短詩，三行（5-7-5音節）

範例：松尾芭蕉的經典作品

歷史：始於17世紀日本

現代：全球流行，主題多元

理解測驗
  1. What is a haiku? (什麼是俳句？)
  2. How many syllables does each line have? (每行有多少音節？)
  3. Who was Matsuo Basho? (松尾芭蕉是誰？)
  4. What are modern haiku about? (現代俳句關於什麼？)
